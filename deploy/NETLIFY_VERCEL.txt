NETLIFY / VERCEL — FRONTEND (TEKIN)
====================================
Netlify va Vercel faqat STATIC sayt (React build) uchun. Django API alohida joyda turishi kerak.

1) BEPUL POSTGRES (masalan Neon)
   - https://neon.tech — ro'yxatdan o'ting, yangi Postgres yarating.
   - "Connection string" ni nusxalang (DATABASE_URL).

2) BEPUL API (Render)
   - https://render.com — GitHub bilan kirib, "New" → "Blueprint".
   - Ushbu loyiha reposini tanlang, render.yaml ishlatiladi.
   - Environment o'zgaruvchilarni to'ldiring:
     * DATABASE_URL = Neon dan nusxa
     * DJANGO_ALLOWED_HOSTS = sizning-api.onrender.com (Render bergan hostname)
     * CORS_ORIGINS = Netlify yoki Vercel domeningiz, vergul bilan:
       https://sizning-sayt.netlify.app,https://sizning-sayt.vercel.app
   - Deploy tugagach, API manzil: https://SIZNING-API.onrender.com

3) NETLIFY (frontend)
   - https://app.netlify.com — "Add new site" → "Import an existing project" → GitHub repo.
   - Netlify avtomatik ildizdagi netlify.toml ni o'qiydi (base = frontend).
   - Site settings → Environment variables:
     * VITE_API_BASE = https://SIZNING-API.onrender.com/api
       (oxirida /api bo'lsin)
   - "Trigger deploy" qayta ishga tushiring (env build vaqtida kerak).

4) VERCEL (frontend)
   - https://vercel.com — "Add New" → "Project" → repo tanlang.
   - "Root Directory" ni frontend qilib belgilang.
   - Loyihada api/[...path].ts — /api/* so'rovlarini Django ga proksilaydi.
   - Environment Variables (Production, Preview):
     * BACKEND_ORIGIN = https://SIZNING-API.onrender.com
       (faqat domen; oxirida /api BO'LMASIN)
   - VITE_API_BASE ni bo'sh qoldiring yoki /api qilib qoldiring (standart).
     Agar to'g'ridan-to'g'ri Render ga murojaat qilsangiz: VITE_API_BASE=https://...onrender.com/api
     va CORS da Vercel domeni bo'lishi kerak.
   - O'zgarishdan keyin "Redeploy".

5) BIRINCHI MA'LUMOTLAR
   - Render Shell yoki "Run command": python manage.py seed_demo
   - Yoki mahalliyda superuser yaratib, Render Postgresga migratsiya qiling.

ESLATMA: Render bepul rejimida server uxlaganda birinchi so'rov sekin bo'lishi mumkin.
Mahsulot rasmlari (media) bepul diskda saqlanadi; Render disk cheklovlari bor — production uchun S3 kabi xizmat keyinroq qo'shiladi.

DOCKER (MONOREPO)
=================
- API image: reponing ILDIZIDAN:  docker build -t dorilar-api .
  (ildizda Dockerfile bor; backend/ ichidagi Dockerfile — faqat context=backend bo'lganda.)
- Frontend+nginx (docker compose ichidagi "web"): ildizdan  docker compose build
  yoki:  docker build -f deploy/Dockerfile.web -t dorilar-web .
- "open Dockerfile: no such file" — build konteksti noto'g'ri: har doim loyiha ildizi
  (dorilarApp), deploy/ yoki backend/ emas (Dockerfile.web frontend uchun ildizni talab qiladi).
